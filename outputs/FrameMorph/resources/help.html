FrameMorph: compose, explain, animate

Build a demonstration like a slide deck. Place images, text, shapes, formulas, graphs, SVG artwork and code on a frame. Use the Properties inspector to edit what you select.

A first animation in one minute

  1. Draw a Circle from the ribbon. It receives a name such as __circle_1.
  2. Duplicate the slide. Drag or resize the circle on the copy.
  3. Click an empty part of the source frame, or its thumbnail. Set Time step to next frame in Frame Properties.
  4. Press Play. The same name connects the two poses automatically.
  5. Save the project folder, then Export video.

F1 opens this guide. Hover over controls for short notes. Changes are undoable with Ctrl+Z.

Objects and frames

Click an object for its name, geometry, appearance, effects and updater. Drag its bounding box to move; drag square handles to resize; use the circular handle to rotate. Hold Shift to constrain movement, proportions or rotation. Double-click text or mathematics to reveal its source editor.

Click the canvas background, a slide thumbnail, or the Frame properties button for frame timing, background, updater generation and the object list. Frame selection returns the timing controls to view.

Names beginning with __ participate in animation. Matching is exact and case sensitive. Ordinary names use the default frame crossfade. Repeated animated names intentionally split or merge. Disconnected pieces inside one selected object remain grouped.

Shift-click objects or drag a selection rectangle to select several. Drag a selected member or press arrow keys to move the whole selection; Shift+Arrow moves ten pixels. The center buttons center the selection as a group. More... provides left/right/top/bottom edge alignment and equal horizontal/vertical gaps (at least three objects). Handles resize and rotate the active object individually. Each group edit has one Undo step. Group selection combines their geometry. Combine images makes one portable raster object in an overlay, horizontal row, or vertical stack; individual source objects are replaced, and Undo restores them. Bring to front / Send to back and Layer remain in Object Properties.

Picture inserts PNG/JPG or SVG as an object. Import slides fits PNG/JPG to the canvas as a complete keyframe. For an imported frame, Edit slide image lifts the background into an editable image layer while preserving authored objects. Extracted pixel objects must be edited individually first.

Animation effects

Construct applies only when an object appears on the next frame. Destruct applies only when it disappears. Matching objects use their ordinary morph or saved updater path instead.

EffectBehavior
Default / FadeOpacity changes smoothly.
None (cut)No transition; changes at the end of its scheduled interval.
Grow / shrinkChanges size about its center and fades.
Slide directionsMoves into or out of the frame in the chosen direction.
Wipe directionsReveals or conceals the original artwork without shrinking it.
Spin and growA full turn with size and opacity changes.
PopOvershoots the final size, then settles.

Effect starts / ends are percentages of the frame transition; 25 to 75 uses its middle half. Choose Smooth, Linear, Ease in or Ease out. The frame's time step controls the overall duration. Repeated plain names pair existing instances; only extras receive lifecycle effects.

Functions, matrices and updaters

Map this object now changes the selected object's current geometry. Prefix (x,y): or z: selects the parser. Coordinates are relative to the current object center, X right and Y up, with 100 pixels per unit by default. Use explicit multiplication.

(x,y):x+1,y+2
z:z*exp(i*pi/4)
(x,y):x+0.3*y,y
z:z+0.2*z^2

An updater specifies the whole trajectory from the original geometry. Save it on each object, then open Frame Properties and press Create next slide from updaters. New and Duplicate never execute saved updater drafts.

z:z+2*(exp(i*tau*t)-1)       circle orbit
z:z*exp(i*tau*t)             full rotation
z:z+2*i*sin(pi*t)            bounce up
z:z*(1+0.2*sin(pi*t))        pulse
(x,y,t):x+t*y,y              shear matrix
(x,y,t):x+0.3*sin(2*y)*sin(pi*t),y

t always runs 0 to 1. duration is the frame time step; seconds=t*duration. A two-second step gives seconds=2*t. The updater must reproduce the original pose at t=0. Changing a committed updater's duration records the next generation's step; regenerate its endpoint to change the saved trajectory.

Property fields use scene.width, scene.height, scene.origin_x/y, object.x/y/width/height/center_x/center_y. Object maps use scene edges and origin_x/y in local map coordinates; origin is the complex scene center offset. The Variables button lists conventions.

LaTeX formula studio

Click LaTeX in the ribbon. Choose a template or enter a mathematical fragment, then Preview. Preview runs in the background. Apply adds a named, editable object. Edit content opens its source later. Moving/resizing existing formula artwork does not recompile LaTeX.

Auto tries fast Matplotlib Mathtext and falls back to Full LaTeX. Full LaTeX uses the approved installed TinyTeX/pdflatex and PyMuPDF. It supports amsmath / amssymb notation, matrices, cases and aligned equations. The rendered transparent artwork and original fragment are saved inside the project. Load/save source files directly, and use Fit/Actual pixels/200% to inspect a preview. Ctrl+Enter previews; Alt+Enter applies.

\frac{-b\pm\sqrt{b^2-4ac}}{2a}
\begin{bmatrix}1&2\\3&4\end{bmatrix}
\begin{aligned}f(x)&=x^2\\f'(x)&=2x\end{aligned}
\begin{cases}x^2&x\geq0\\-x&x<0\end{cases}

Enter a formula, not a complete document. Shell escape, file commands and custom preambles/macros are not supported. LaTeX has a 20-second compilation timeout. If a package or command is missing, the error stays in the preview editor. Fast Mathtext remains available without the optional backend.

Image studio and pixel formulas

Select an image and click Edit content or Image filters / pixel formulas. Any selected object can be raster-edited. Crop coordinates refer to original image pixels. Width and Height set the resulting image and canvas-object size. Optionally lock output aspect to the crop, with width driving height. Use ordinary object handles to resize it visually.

Adjust brightness, contrast, saturation, blur, grayscale, sepia, inversion, sharpen, edges or threshold. Flip horizontally or vertically. Tint preserves image detail; white tint restores the original colours. Every preview starts from the saved original, so repeated previews do not accumulate blur or compression. Reset to original removes the settings. The original pixels and recipe survive save/reopen; Undo restores the previous edit.

Pixel maps run after the selected filters. Channels r,g,b,a are 0 to 1; x,y are normalized image coordinates from 0 to 1. All output channels read the same pre-map pixel, then clamp to 0..1. Non-finite results are rejected.

(r,g,b,a):1-r,1-g,1-b,a         invert
(r,g,b,a):g,b,r,a               cycle channels
(r,g,b,a):r,g,b,a*x             alpha gradient
(r,g,b,a):clamp(1.2*r,0,1),g,b,a
(r,g,b,a):r*sqrt(x),g,b,a

Use min(a,b), max(a,b), pow(a,b), clamp(value,low,high), sin/cos, abs, sqrt, log and exp. Explicit multiplication is required. Processing happens before playback; animation uses the resulting cached artwork.

To combine images, Shift-select them and choose Overlay, Side by side or Vertical stack in Properties. Alpha is composited in layer order for an overlay. The result is one object that can be resized, filtered, mapped and animated. Images are bounded to 8192 pixels per edge and 16 megapixels for processing/output.

Source code and SVG

More... > Source code block opens a code preview editor. Choose Python, C++, JavaScript or plain text, dark/light theme, font size and line numbers. Source text is stored in the project and never executed. Python uses its standard tokenizer; C++/JavaScript use lightweight lexical colouring, not a compiler.

Picture accepts SVG files. More... > SVG artwork accepts source directly. SVG source is embedded and rendered with the approved PyMuPDF backend. Paths, fills, strokes and supported text are rendered into transparent artwork. External file/network resources, scripts and foreignObject are unsupported. Some SVG filters/fonts may differ from a web browser. Raster editing an SVG preserves its source construction for later content edits; re-editing the SVG source reconstructs it and clears raster edits.

Shortcuts and troubleshooting

Space / Escape / F1Play-pause / Cancel gesture / Help

If nothing moves, check exact names and the __ prefix. A closed orbit needs an updater, because identical keyframes alone do not describe the path. If a contour morph folds, use clearer regions or change the geometry; existing advanced correspondence data is preserved in project JSON.

Imported flat-background diagrams work best. Photo segmentation, background reconstruction, true 3D, audio and arbitrary Manim scripts are outside this editor. Pixel extraction uses colour tolerance and eight-connectivity; hold Shift to add disconnected pieces or Alt to subtract. Add/erase brushes correct boundaries.

Save retains portable images, masks, original edited-image pixels, native source and parameters. Autosave recovery is available. Export uses the same CUDA renderer as preview and finalizes MP4 only after successful encoding. Preview speed depends on object count, detail and GPU memory. Unchanged artwork stays in a bounded GPU cache. Transparency coverage agrees with authored keyframes to prevent brightness flashes at the start and end of playback. Optional LaTeX/SVG construction needs the installed helper tools, but reopening/moving/exporting cached artwork does not.
